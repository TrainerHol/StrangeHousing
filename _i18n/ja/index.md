FF14 には、プレイヤーが作成したジャンプパズルが 1000 個以上存在しているのをご存知ですか？私たちコミュニティは、全データセンターにあるこれらの素晴らしい作品を発見・制作・記録しています。

## パズルを探す

次のチャレンジを探していますか？[パズル検索ツール](https://search.xivpuzzles.com)で以下のことができます：

- ワールドやデータセンターごとのパズル検索
- 難易度、[ギミック](/subtypes)、その他の条件でフィルター
- ハウジングエリアの正確な住所を確認

{: .info }

> パズルやメイズ、レーストラック、その他のクリエイティブな作品を設置したお家をお持ちですか？データベースに登録しませんか？

[投稿はこちら](https://forms.gle/ZPhT29Q6Y3shQnWi8){: .btn .btn-purple }

## 進捗を記録

公式のストレンジハウジングカードシステムで実績を披露しましょう：

- Discord で`/clear <パズルID>`を使ってクリア記録
- 特別な実績でバッジを獲得
- `/setcardsettings`でカードをカスタマイズ
- [badges.xivpuzzles.com](https://badges.xivpuzzles.com)で獲得可能なバッジを確認

![ストレンジハウジング進捗カード]({{ site.baseurl }}/assets/images/bazcard.png)

## コミュニティに参加

私たちは単なるデータベースではありません。ジャンプパズルの制作や挑戦を愛する活気あるコミュニティです！大規模なイベントやコラボ制作、建築アドバイス、タイムアタックなど、様々な活動を行っています。

### パルクールリーグ

自分の実力を試してみたい方は、パルクールリーグに参加してみましょう。難易度別に厳選されたパズルに挑戦し、全てクリアすると Discord で特別なロールが付与されます！

### 定期的なコミュニティイベント：

- パズルクロール（みんなで一緒にクリアする会）
- ギル報酬付きクリア報酬
- ハウジングデザインコンテスト
- 定期的な抽選会とプレゼント企画

## リソース

詳しく知りたい方は、メニューから以下の詳細ガイドをご覧ください：

- 建築テクニック
- ジャンプ技術
- 評価システム
- ハウスの種類と分類

ストレンジハウジングは、コミュニティ全体で発見してきた知識を集約することを目指しています。建築やジャンプのテクニック、評価システム、ハウスの分類など、詳細な情報をここで見つけることができます。ここにある情報の一部は他の場所で最初に発見されたかもしれませんが、全ての情報は私たちのメンバーによって独自に検証され、名称や説明は私たちの理解に基づいています。この情報がジャンプパズルやハウジング愛好家の皆様のお役に立てば幸いです。ぜひ自由に共有してください。
