# パズルリーグへようこそ！

パズルリーグの仕組みはシンプルです：私たちがパズルのリストを提供し、あなたがそれをクリアするだけです！サーキット内のすべてのパズルをクリアすると、バッジを獲得できます！各サーキットは、同じ地域の同じ難易度のパズルで構成されています（例：NA 1★ サーキット、EU 2★ サーキットなど）。クリア達成に応じてバッジとロールが付与されます。

## 地域のすべてのサーキットバッジを集めると何が起こるの？

- バッジがロールにアップグレードされます。
- 簡単なパズルに戻ることで、新しい友達を作ったり、新しいジャンパーにパルクールを紹介したりする良い機会となります。
- Discord の Social Jumper ロールをピンしたり、PF を立てたりして、楽しんでいただくことを強くお勧めします！

_(リーグシーズン終了時に、地域ごとの最高バッジの永続版が付与されます。4★ バッジは両地域でカウントされます)_

## ルール

パルクールリーグは楽しく社交的なものであり、厳しく管理や検証をしたいものではないため、ルールは最小限に抑えています。バッジは楽しむためのものなので、名誉システムで運営しており、以前にパズルをクリアしている場合でも、新しいクリアを使用することをお願いしています。リーグ用に選ばれたパズルの中には、しばらく見ていない古いビルドもあるかもしれません。

また、新しい地域でアルトを作成した場合、エンピレアムと白金通のパズルにアクセスするのが難しい場合があります。Discord でフレンドテレポを依頼することもできますが、取得できない場合は、アルト地域のバッジには必要ありません。

つまり：名誉システムを使用し、新しいクリアのみを投稿し、エンピレアムと白金通のパズルはアルト地域のバッジには必要ありません。

## バッジの申請

パズルをクリアしたら、対応する文字にリアクションし、バッジ申請チャンネルにクリア画像を投稿し、サーキットバッジを申請する準備ができたらモデレーターにピンしてください。申請内容が不明な場合は、サーキット内のすべてのパズルをクリアしたことを管理者に伝えれば、サーキットリストへのリアクションを確認してバッジを付与します。
