## **Ghosting calculator**:

Haise 制作

ゴーストパズルの作成をより簡単にする便利なツールで、void sphere の反対側にトリガーを配置する位置を計算します。

このツールは、ハウジングスフィアの表面上の 50 ヤルム以内の座標を計算します。黄色い矢印が北を示します。

**手順**

- スフィアを希望の位置にドラッグするか、座標を入力して「validate」をクリックすると、その位置に最も近い表面上の点にスナップします。
- BDTH には整数を入力してください。四捨五入すると無効な座標や距離になります。BDTH の UI では数値が四捨五入されて表示されますが、実際の値は設定されています。

<https://trainerhol.github.io/FFXIV-Ghosting-Calculator/>
