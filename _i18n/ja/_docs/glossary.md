# Jump Puzzle Glossary

<sub>_このドキュメントは機械翻訳を使用して作成されました。翻訳の改善提案を歓迎いたします。_</sub>

## BLU Cheese / 青魔道士チーズ戦術 🧀

- 蘇生可能な味方の助けを借りて、自爆を使用してパズルの一部をスキップする方法。多くのビルダーから非推奨とされています。

## Bodybangers / 体当たり障害物 🎢

- 空中の障害物や障壁により、特定のプラットフォームの側面に着地したり、特定の側面から飛び出したりする必要がある仕掛け。

## Bonus Stage / ボーナスステージ 🎉

- メッセージブックやゴール地点の後に追加される区間や追加チャレンジ。

## Builder's Advantage / 製作者有利 🛠️

- パズルの製作とテストを通じて、製作者は一般のジャンパーと比べて大きなアドバンテージを持つことがあり、難易度を過小評価する可能性があります。この有利さは、製作過程を見ていた人やテストを手伝った人にも共有されることがあります。

## Bullet Lift / 弾丸リフト 🚀

- 地面近くの家具の持ち上げ効果を利用するため、移動キーとジャンプキーを素早く連打する必要がある技法。ドレスフォームや一部のハウジングスキンで見られます。

## Camera Obstruction / カメラ妨害 📷

- 窓を使用してチャレンジャーのカメラワークを妨害し、難易度を上げる手法。

## Ceiling Lift / Elevator / 天井リフト・エレベーター ⬆️

- 天井近くの家具を使用して虚空にジャンプする技法。主にスターグローブやドラゴンランプなどが使用されます。パズルの入り口としてよく使用されます。

## Checkpoints / チェックポイント ✅

- 虚空の侵入や段差のある床を設置することで、ジャンプパズル中のプログレスを保存し、落下時に全進捗を失わずに済むようにする仕組み。

## Cloud Puzzle / 雲パズル ☁️

- 虚空空間の中で、雲の水分のように家具が互いに離れて浮かんでいるジャンプパズル。フェージングや虚空ジャンプのあらゆる種類に対して耐性があります。

## Corner Grab / コーナーグラブ 🔄

- 弱いコーナーやボディバンガーの周りをジャンプして、落下せずに反対側の着地面に曲がり込むことが可能な技法。

## Cube Lift / キューブリフト 📦

- キューブ全体をリフトとして使用し、通常では不可能な方法でジャンプパズル内の他の家具に到達する技法。ゴブレットでよく見られます。

## Doze Gate / ドーズゲート 🛏️

- /doze コマンドを使用して近くのベッドにテレポートする技法。壁、床、天井を通り抜けることができます。一般的なパズルの入り口として使用されます。

## Emote / エモート 🎭

- サブタイプ (E) - パズルには/sit や/doze などのエモートと家具のインタラクションが必要な箇所があり、これらは隠されている場合があります。(E+)はエモートが家具の移動（「スライド」）をトリガーすることを示し、閉じ込められてリセットが必要になる可能性があります。

## Expedient / エクスペディエント ⚡

- 学者レベル 90 で使用可能。自身と周囲のパーティメンバーの移動速度を 30%上昇させます。スプリントだけでは足りないパズルで有用です。

## Fake Platforms / 偽装プラットフォーム ❌

- 意図的に当たり判定のない家具を使用して、チャレンジャーを誤誘導し、進捗をリセットさせる可能性のある仕掛け。

## Forbidden Phasing / 禁断のフェージング 🚷

- 壁に向かって中央から歩き、約 2 歩でフェージングが発動する前にジャンプすることで、一部の家具をすべてフェージングせずに通り抜けることができる技法。

## FPS Manipulation / FPS 操作 🎮

- ジャンプパズルの精密なジャンプを FPS を上下させることで簡単にすることが可能ですが、神レベル以下のほとんどのパズルには難しいジャンプを管理する他の方法があります。

## Furniture Hitboxes / 家具の当たり判定 📏

- 特定の家具の当たり判定を使用して、チャレンジャーを落下させたり滑り落とさせたりする障害物を作成し、難易度を上げる手法。

## Ghost / ゴースト 👻

- サブタイプ (G) - ゴースティングとも呼ばれ、キャラクターの位置に応じて家具が決められた順序で消えたり再表示したりするパズル。(G+)は複数段階のゴースティングがあり、決められた順序で消えたり再表示したりします。

## Ghost Lift / ゴーストリフト 🎈

- ヘビーリフティングやアップワープとも呼ばれます。物理的な接続なしで、家具が垂直に相互作用することで作られる拡張されたリフト。

## Goal / ゴール 🎯

- パズルアドレスに設定された追加目標で、特定のテクニックの使用を避けたり、他の特別なルールに従うことを求めます。ジャンプパズルのメッセージブックがゴールラインにない場合にも適用されます。

## Goblet Shell / ゴブレットの外殻 🏺

- ゴブレットの家やルームでは、ハウジングキューブの外側の縁を歩くことができます。これが特定のパズルのメカニックとなることがあります。ミスト以外のハウジングゾーンの柱にも適用されます。

## Headbangers / ヘッドバンガー 🤕

- ジャンプの仕方によってチャレンジャーを落下させるために、より高い位置に家具を配置する手法。

## Henteko Blockade / へんてこブロッケード 🚧

- フェージングを防ぐのに十分な高さだが、進行を妨げるには十分な低さの位置に、固体の家具を床の上に浮かせる手法。必ずしもフェージングが不可能というわけではありません。

## High Precision / 高精度 🎯

- 特定のジャンプを成功させるために正確な角度と勢いが必要で、通常は難易度を大幅に上げる要素。

## Invisible Wall Pegs / 不可視の壁ペグ 🧱

- 壁の後ろに家具を配置し、その端に着地できるが見えない状態にする手法。

## Job Gate / ジョブゲート 🎮

- サブタイプ (J) - アンアヴァン、エルーシヴジャンプ、エーテリアルマニピュレーション、地獄のインプレス/エグレスなど、特定のジョブアビリティでのみ越えられるギャップがあるパズル。(J+)は青魔道士などの特定のジョブが必要な協力パズルや、特定のジョブアビリティでのみギャップを越えられる場合を示します。

## Jump Fatigue / ジャンプ疲労 😩

- ジャンプパズルで疲れ果てた状態を表す用語。高精度や高難度で引き起こされやすい。短い休憩を取るか、別の日に戻ることで回復します。

## Koi Jump / コイジャンプ 🐟

- 大きなジャンプの際にスピードブーストをオフにして、ジャンプを超えないようにする技法。パズルには存在せず、おそらく不可能な理論です。

## Leap of Faith / 信仰の跳躍 🏃‍♂️

- チャレンジャーが遠く離れた、しばしば小さなプラットフォームに着地するために大きな下降ジャンプを行う必要がある仕掛け。難易度を上げます。

## Logic / ロジック 🧩

- サブタイプ (L) - ゴースティングとスライドを非従来的な方法で使用し、ジャンプパズルの本質を再定義するパズル。他のタグの修飾子として見ることができます。(L+)は重要な障害物を解決するために一緒に使用される可能性のあるテクニックの深い理解が必要です。

## Moon Flute / ムーンフルート 🎶

- 青魔道士が 10 個の魔法を習得した後に使用可能。移動速度を 30%上昇させます。スプリントだけでは足りないパズルで有用です。

## Mystery / ミステリー 🕵️‍♂️

- サブタイプ (M) - 見つけにくい、または迷路のような道筋、解決が難しい家具の組み合わせ、トリッキーで誤解を招く、または欺瞞的な要素があるパズル。(M+)は難易度評価に大きく影響するほど複雑なミステリーを示します。

## Ninja Jump / 忍者ジャンプ 🥷

- 忍者の壁や家具の組み合わせから、ジャンプする前に速度を蓄積できない状態でジャンプする技法。

## Ninja Passive Speed / 忍者パッシブスピード ⚡

- 常時移動速度が 10%上昇します。ジャンプパズルは通常これを考慮してバランス調整されていませんが、より速い速度が使用されていない場合、一部のジャンプをよりスムーズにする可能性があります。

## Ninja Walls / 忍者の壁 🧱

- グレイドパーティションなどの仕切りの下部のラインを使用して、歩いたりジャンプしたりできる狭い表面を作成する技法。

## No Media / メディア禁止 🚫

- サブタイプ (X) - ビルダーからの配信/録画禁止リクエストの対象となるパズル。一部のビルダーは低プロファイルを保ちたい、またはパズルを神秘的に保ちたいと考えています。彼らの意向を尊重してください。

## Obscure Entrance / 隠された入口 🔍

- 時には非常に見つけにくいパズルの入口。隠されたドーズゲート/アップワープを含んでいたり、入口に到達するために一連の手順を実行する必要がある場合があります。

## Partition Transfer / パーティション移動 🔄

- 空中に浮かぶ忍者の壁パーティションの縁の片側から、近くの家具の助けを借りずにコーナーを回って反対側に移動する技法。この技法の難易度は、チャレンジャーが使用する方法と練習量によって大きく異なります。

## Peloton / ペロトン 🚴‍♂️

- レベル 20 の遠隔 DPS で使用可能。移動速度を 20%上昇させます。いくつかのジャンプパズルで非常に重要です。スピードブーストの黄金基準で、クールダウンなしで一貫して遠くまでジャンプすることができます。

## Phase Pad / フェーズパッド 🛋️

- イルメグランプやボムコルドロンなどのアイテムの当たり判定の上でバランスを取ることで、特別なジャンプが可能になります。フェージングが発動して落下する前に、その場で数歩走ってから任意の方向にジャンプします。この動作により近くの家具がフェージングする可能性があります。この技法は禁断の技法とは異なるものとされています。

## Phasing / フェージング 🌌

- サブタイプ (P) - 家具に向かってまっすぐ走り続けることで通り抜けられるようになるパズル。フェージングは多くの場合禁止されているのでパズルのルールを確認してください！(P+)は立っている場所を通り抜けないようにするためにジャンプフェージング（「禁断の技法」）が必要です。

## Pipe Phasing / パイプフェージング 🚰

- 工業用壁パイプなどの一部の家具は、非常に長いフェージング範囲を持ち、極端に遠く（8y-15y）に移動するまでフェージングが継続します。椅子に座れる距離まで離れれば十分です。他の場所でのフェージングやルームリフトの使用でも修正できる場合があります。注目すべきは、他のオブジェクトの近くのパイプを、他のオブジェクトをフェージングアウトすることでフェージングアウトできることです。

## Pumps / ポンプ 🔄

- 複数の壁掛けアイテムのスナップが交差し、他の表面にアンカーされている場合、複雑なスライドメカニズムをループさせることが可能です。(E+)で表記されます。

## PvP Door / PvP ドア 🚪

- ドアの上部に着地するためにフェージングが必要なドアパーティションで、ドアが開くと無効になります。多数のチャレンジャーが存在する場合に問題となります。警告：これを使用してコースを「ロック」することができるため、5 スターレベル以下での使用は推奨されません。

## Return Dash / リターンダッシュ 🔙

- 高所から落下して固定された後、ジョブゲートで使用されるようなジョブダッシュを使用して、パズルで落下した地点に戻ることが可能な場合があります。この技法は信頼性が低く、依存すべきではありません。

## Semi-Solid Void Barrier / 半固体虚空バリア 🌌

- 極めて薄い虚空の壁のスライスを使用して、虚空ジャンプに必要な条件を生成します。高 FPS でより固体化し、低 FPS でより固体化が減少します。

## Sit / Doze Jump / 着座・仮眠ジャンプ 🛋️

- 適度な高さの壁の近くにある椅子やベッドに/sit や/doze コマンドを使用して座り、通常のジャンプでは失敗するような壁や他の家具の上に着地することが可能な技法。構築が困難です。

## Sit Gate / 着座ゲート 🚪

- 椅子や椅子のような物体に進むために、/sit コマンドを使用して少し上方や横方向にテレポートする必要がある仕掛け。

## Slides / Locks / スライド・ロック 🔒

- 着座、仮眠、正面玄関へのリセット、または蘇生により、他の家具に詰め込まれた特定の家具が一時的にその人だけのために位置を変更することがあります。通常、複数のパーティションと壁掛けアイテムが関係します。

## Speed / スピード ⚡

- サブタイプ (S) - 早期または複数の長距離ジャンプにより、スプリントのクールダウンを待つ必要があるパズル。ジャンプが最大ペロトン範囲付近/以上の場合にのみ適用されます。エクスペディエント（学者）やムーンフルート（青魔道士）などの追加のスピードバフで対処できます。

## Sprint / スプリント 🏃‍♂️

- 20 秒間移動速度を 30%上昇させ、1 分のクールダウンがあります。多くのジャンプパズルで必要不可欠です。

## Staggered Lift / 段階的リフト ⬆️

- ムービングアップワープとも呼ばれ、近くのリフトを使用するために、即座に機能させるか、ジャンプで機能させるためのスティッキングを生成するために、横方向にジャンプする必要がある場合があります。

## Staggered Phase Lift / 段階的フェーズリフト ⬆️

- 一部の家具をフェージングまたは禁断のフェージングを使用して通り抜け、その底部にスティッキングしてからリフトとして使用する技法。これは主に神パズルで関連します。

## Structure Puzzle / 構造パズル 🏗️

- 多くの家具が接触して視覚的に構造を形成し、空中に単独で浮かぶ家具が少ないジャンプパズル。これらはより現実的に見え、一部の家具は複数回使用される可能性がありますが、構造パズルは禁断の技法、フェージング、および/または虚空ジャンプに対して脆弱性を持つ傾向があります。

## Subtypes / サブタイプ 🏷️

- タグとしても知られ、パズルとそれを完了するために必要な技法についての説明です。

## Upwarp / アップワープ ⬆️

- 特定の家具の下でジャンプすると、次に利用可能な立ち位置の表面まで吸い上げられる可能性があります。

## Void Jump / 虚空ジャンプ 🌌

- サブタイプ (V) - 虚空ジャンプを使用してのみ越えられる垂直のギャップがあり、パズルを完了するために必要なパズル。虚空ジャンプは、着地したい場所の下で 3 秒間まっすぐ虚空の上を走ってからジャンプすることで実行されます。

## Void Wall / 虚空の壁 🚧

- ハウジングキューブの端の外側にある、通り抜けることのできない不可視の壁。

## Warping / ワーピング 🔄

- チャレンジャーが下の表面にテレポートされる現象で、通常はプラットフォームの端から歩き出す際に発生します。ハウジングキューブの端や、床に隙間が存在する場合にハウジングキューブの外側で発生します。
